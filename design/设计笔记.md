# 交互小说引擎 · 设计笔记

> 宪法。改代码前先读这里。

## 0. 一句话

**一个生成"小城旧案"的引擎：每局摇出一座镇子、一群人、一桩悬案，玩家走进去问人找物拼真相，最后指认——然后发现没看到的另一半。**

## 1. 类型与体验

- **类型**：悬疑 / 小城旧案。玩家是外来者（调查人），用 [选项点击 + 打字指令] 双模式探索。
- **画面**：复古纸质 / 打字机。CSS 排版，深暖纸色，衬线字体。
- **结局**：指认（可多次）→ 揭示真相全图 → **"你错过了什么"** → 再来一局。

## 2. 三条铁律（"严谨"的实现方式）

### 2.1 真相倒推，禁止正推

故事不是"先有场景再编真相"，而是：

```
1. 生成世界（镇子、三层历史、机构、传闻）
2. 生成人物（欲望/恐惧/秘密 三件套，互相冲突）
3. 生成关系网（先建再验：无孤立者、无单向仇恨）
4. ★ 生成真相（凶手、动机链、行动链、掩盖链）
5. ★ 从真相推导线索——每条线索都是真相的一个"投影"
6. 线索分布到地点/人物/日程
```

**线索永远先于线索存在。** 不存在"收集了但没用"的线索；
每条线索都指向真相图里一个真实存在的节点（有测试断言）。

### 2.2 不在场证明（alibi）由日程自动保证

严谨与否全在时间线。引擎的做法：

- 每个人有 6 个时段（清晨/上午/正午/午后/黄昏/入夜）的日程。
- 案发时段是**先生成的**，只有"该时段日程有缺口"的人才能成为凶手。
- 凶手的日程上那个时段是**一句谎**（声称在家），和证词/物证矛盾。
- 至少 2 人拥有**可核实的真实不在场证明**（自动洗白），
  1 个红鲱鱼（有动机假象但可被线索洗清），1 个目击碎片。

**由此，指认永远是逻辑可解的**：动机链、行动链、掩盖链各自独立指向凶手，
任何一条链走通就能破案（构造性可解，有测试断言）。

### 2.3 谎言是状态机，不是一次性对白

每个人物对每个话题有一个**立场**：

```
说真话 ──→ 回避 ──→ 撒谎 ──→ 拒绝开口
```

- 立场由 [所知 × 动机] 决定：他不知道就不会说；他知道但动机让他藏。
- 每条谎言有**裂缝**：1~2 件能击穿它的具体证据。
- 玩家**出示证据** → 立场降一级（撒谎→回避→部分承认→全盘托出）。
- **讯问即玩法**：收集证据是为了撬开嘴。

## 3. 世界观（"大一点"的实现）

每局小镇有三层历史，每一层都是活的：

```
31 年前的大火 ──→ 谁家败落、谁家崛起 ──→ 恩怨种子
12 年前的倒闭 ──→ 失业、出走、欠债   ──→ 关系裂缝
4 年前的征地   ──→ 新仇、搬迁、收买   ──→ 案发动机的土壤
```

- **机构**：祠堂/教堂、镇政府、老码头、倒闭的工厂、老宅。
- **传闻**：1~2 条镇上传闻，**其中一条藏着真线索**（传闻不是装饰）。
- **人物**：6 人左右，各带一段与历史层纠缠的往事。

## 4. 人物规格（"丰富"的实现）

每个人物：

| 层 | 内容 |
|---|---|
| 身份 | 姓名（有含义）、年龄、职业、初印象 |
| 三件套 | **欲望**（现在想要什么）/ **恐惧**（在躲什么）/ **秘密**（藏着什么）——三者必须互相冲突 |
| 声音 | 口头禅、说话节奏、**撒谎时的小动作**（"说到关键处总要摸烟盒"） |
| 关系 | 血亲/旧情/债务/背叛/共享秘密，带深度权重 |
| 日程 | 6 时段的去向（alibi 的来源） |
| 所知 | 对每个真相节点的知识等级：0 不知道 / 1 碎片 / 2 全知 |

## 5. 世界生成的角色谱

| 角色位 | 作用 |
|---|---|
| 权威（镇长/神父/族长/医生） | "本应知道"但被牵扯的人 |
| 老住户 | 镇子的活记忆（历史层知识入口） |
| 新贵 | 旧灾难的得利者（动机嫌疑） |
| 苦主 | 旧灾难的受损者（动机嫌疑） |
| 边缘人（哑巴/钟表匠/守夜人） | 看见一切、说不出话的目击 |
| 死者相关人（未亡人/继承人/仇家） | 与案件的核心纠缠 |

## 6. 玩法循环

```
去 [地点]       移动，消耗时段；地点可翻找线索
看 [物品/线索]   细看，线索进笔记本
问 [人物] 关于 [话题]   对话引擎按立场生成回答
出示 [证据] 给 [人物]   击穿谎言
笔记              右侧栏：人物/线索/日程/时间
休息              推进到下一时段；入夜后一天结束
指认 [人物]       可多次；错误指认消耗信任与时段
```

- 没有失败。只有"第几天破的案、错过了多少"。
- **揭示屏**：完整动机链、每个人撒的谎与真相、"你没看到的另一半"、本局种子。

## 7. 技术

- 零依赖，双击 `index.html` 可玩。
- **带种子随机**（可复现）：每局一个种子，可分享、可存档。
- 模块：rng / names / world / people / relations / truth / clues / dialogue / actions / game / ui / main。
- **测试是严谨的一部分**：`test/logic.js` 断言——线索全部指向真实节点、
  凶手日程有缺口、关系网无孤立者、指认构造性可解、不知情者不会说漏。

## 8. 开发顺序

1. 世界内核（rng + 镇子 + 历史层 + 传闻）✔
2. 人物与关系网
3. 真相与线索推导
4. 对话引擎（谎言状态机）
5. 玩法循环 + 指令解析
6. 纸质 UI + 打字机效果
7. 指认与揭示
8. 逻辑测试 + 打磨

## 9. 已定决策

| 决策 | 结论 |
|---|---|
| 类型 | 悬疑 / 小城旧案 |
| 画面 | 复古纸质 / 打字机（CSS 排版，不做画面） |
| 玩法 | 选项点击 + 打字指令双模式 |
| 逻辑 | 真相倒推、alibi 由日程保证、谎言状态机 |
| 世界观 | 三层历史 + 机构 + 真线索传闻 |
| 人物 | 6 人，三件套冲突，带声音与日程 |
| 随机 | 带种子，可复现可分享 |
