# 小城旧案 · 交互小说引擎

一个**生成**"小城旧案"的引擎。每局摇出一座镇子、一群人、一桩悬案，
你走进去问人、找物、拼真相、指认凶手——然后发现没看到的另一半。

## 怎么玩

双击 `index.html`。零依赖、零素材，不用联网。

- 可以**点按钮**，也可以**打字**：`去 码头` / `翻找` / `问 苏望秋 关于 出事那晚`
  / `出示 花坛新土 给 苏望秋` / `笔记` / `指认 苏望秋`
- 输入 `帮助` 查看全部指令
- 右边是**笔记本**：时间、人物、线索、不在场证明、镇上传闻
- 破案不是唯一目标——**每局结束时，会告诉你错过了什么**

## 严谨是怎么保证的

不是"写得认真"，是**工程保证**。三条铁律（详见 `design/设计笔记.md`）：

1. **真相倒推**——先定凶手、动机链、行动链、掩盖链，线索是真相的"投影"。
   每条线索都指向真相图里一个真实存在的事实节点。
2. **不在场证明由日程保证**——凶手的案发时段是一句可证伪的谎；
   红鲱鱼的时段是可核实的话；目击者真的在现场附近。
3. **谎言是状态机**——说真话 → 回避 → 撒谎 → 拒绝开口。
   出示证据按链施压，一次撬开一条。

## 测试

```powershell
node test\logic.js    # 35 项：不变量 + 完美玩家 + 错误指认 + 300 局模糊测试
node test\demo.js 冬至渡   # 打印一整局，用于检查文字质量
```

`logic.js` 不是走过场：

| 测试 | 证明什么 |
|---|---|
| 线索→事实完整性 | 没有"收集了但没用"的线索 |
| 凶手的谎 ≠ 现场 ≠ 家 | 不在场证明真的能拆穿 |
| 没人隐瞒自己不知道的事 | 对白永远自洽 |
| **完美玩家模拟** | 从零开始按最优路线走，**必须能破案**（构造性可解） |
| 错误指认 | 指认红鲱鱼必须失败，且给出可核实的反证 |
| **300 局模糊测试** | 每个种子下所有核心不变量都成立 |

## 一个"种子"的用法

- 每局的真相由种子决定。分享种子 = 分享同一桩案子：
  "我玩了一局雾渡镇，凶手谁都没想到——种子是 `白露渡`"
- 控制台敲 `LittleRoom.newGame('你的种子')` 可以重开指定的一局

## 世界观

每局镇子有**三层历史**（三十年前的大火 → 十二年前的倒闭 → 四年前的征地……），
每家每户的恩怨都从这三层里长出来。镇上传闻不全是假的——
**其中一条藏着真线索**。
